## Spacing Scale

Base grid = **4px** (Tailwind unit). Declared values used across auth + shell (all multiples of 4):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Icon-to-text nudges, inline gaps |
| sm | 8px | Compact element spacing |
| — | 12px | Field row internal gaps (`gap-3`), tight stacks |
| md | 16px | Default element spacing, card/option padding (`p-4`) |
| — | 20px | Intra-form field gap (`gap-5`), horizontal page padding (`px-5`) |
| lg | 24px | Section padding, vertical rhythm (`py-6`) |
| — | 28px | Form-group gap (`gap-7`) |
| xl | 32px | Status-panel padding (`p-8`), layout gaps |
| — | 44px | **Min touch target** — inputs (`h-11`), password show/hide toggle (`w-11`) |
| 2xl | 48px | Primary button height (`h-12`), brand-panel padding (`p-12`), major breaks |
| 3xl | 64px | Page-level spacing where needed |

Exceptions (documented, intentional micro-spacing — NOT on the 4px grid): **2px** (`0.5` — `mt-0.5` icon optical alignment, `gap-0.5`), **6px** (`1.5` — label→field gap `gap-1.5`), **10px** (`2.5` — checkbox→label gap `gap-2.5`). These half-steps come from the existing scaffold and are the only permitted off-grid values; do not introduce others.

Mobile-first: comfortable tap targets ≥44px on every interactive control; inputs sized at 16px text to prevent iOS zoom.

## Typography

Exactly **4 size roles** for this phase. **Core UI weights = 2: regular 400 + semibold 600** (Plus Jakarta Sans). The **display face (Bricolage Grotesque) is headings-only and ships at a single fixed weight, 800 extrabold** — a display treatment, not a body-weight ramp step (auto-applied to `h1–h4` via `globals.css` with `-0.02em` tracking).

| Role | Size | Weight | Line Height | Notes |
|------|------|--------|-------------|-------|
| Body | 16px | 400 | 1.5 | Default (`font-sans`). Input text sized 16px (`text-base`) to prevent mobile zoom. Form intro paragraphs may use 15px (`text-[15px]`) as a body-large variant. |
| Label | 14px | 600 | 1.4 | Field labels, links, nav/menu items, buttons. Helper/caption text uses 12px (`text-xs`) at 400. |
| Heading | 20px | 800 | 1.2 | Section / status-panel headings (`text-xl`, display face). |
| Display | 30px | 800 | 1.15 | Page H1 — "Log in to your kita.", "Create your account." (`text-3xl`, display face, `leading-tight`). |

Utility: `.eyebrow` — Space Mono, uppercase, `0.16em` tracking, `0.72rem`, weight 700 — used as the small kicker above headings (e.g. "Welcome back", "Coming soon"). `.tabular` (mono tabular numerals) is defined but not exercised in Phase 1 (no prices yet).

## Color

60 / 30 / 10 mapping to the implemented palette. Green is the primary identity; **gold (spark) is reserved and sparing — it must never overpower the green** (design-system rule). **Never communicate state by color alone — always pair with text or icon** (project accessibility rule).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F4F3EA` paper (`--background`, `bg-paper`) + `#FFFFFF` surface (`--surface`, cards/inputs/nav) | App canvas + white surfaces (auth form column, shell header, cards). |
| Secondary (30%) | `#0C6B4E` kita-green (`--primary`) + `#E3F0E9` kita-green-soft (`--secondary`, selected/success-tint surfaces) | Primary buttons, links, active nav, selected states, brand mark, auth brand panel background, "check your email" panel. |
| Accent (10%) | `#F2B32C` spark gold | Reserved — see explicit list below. |
| Destructive | `#D64545` (`--destructive`) | Validation/field errors, form-level auth error banner, and any session-ending affordance styling. Sparingly. |

Accent reserved for (explicit — never "all interactive elements", never primary buttons, links, body text, or form controls):
- Pushpin dot signature (`.pin`) — bulletin-board motif on the logo mark and brand panel.
- Highlighter marker (`.marker`) behind a single key brand word.
- Brand-panel eyebrow (`text-spark`) and the emphasized "Your kita." word.
- Aspirational detail (small icon/badge accent) on the **"Become a verified seller"** entry point in the shell — as a highlight only, not the button fill (the CTA fill stays green or bordered-neutral).

Semantic tokens available (from `globals.css` `:root`): `--muted #ECEBDD`, `--muted-foreground #4F5B53`, `--border #E3E2D4` (`border-line`), `--ring #0C6B4E` (on-brand focus outline, already global via `:focus-visible`).
